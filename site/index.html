如何阅读

这里展示的是价格指数，不是均价

同比以上年同月为 100，适合观察中长期变化。比如 98.5 表示较上年同月下降约 1.5%。

环比以上月为 100，更灵敏地反映近期变化。比如 100.3 表示较上月上涨约 0.3%。

定基/累计2011–2022 年为轮换基期的定基指数；2023 年起为年内累计同比，不宜直接连成长期序列。

数据来源为国家统计局。网页数据由仓库主 CSV 自动生成，月度更新后随 GitHub Pages 同步发布。
